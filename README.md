# 侯康峰 · 个人档案库（作品集网站）

深空科幻风格的个人档案库：**首页总看板 + 3D 旋转地球 + 关于我（含成长轨迹 · 宇宙穿梭时间轴）+ 作品集 + 学习博客 + 地点地图**，
支持网站内**可视化增删改**内容，数据保存在本地电脑，并可一键导出**静态只读版**上传云端供他人观看。

> 设计参考：借鉴了 [rainzt.cn 作品展示页](https://rainzt.cn/portfolio/) 的作品页布局（眉标/大标题/技能标签/双按钮/滚动提示/状态徽章/欢迎卡片/页脚徽章与运行时间）并融入本深空科幻主题。

## 关于我（含工作经历 · 成长轨迹）

- 个人简介 + 数据画像（核心方向 / 技能标签 / 证书 / 个人特长）
- **深空 3D 时间轴**：光点沿 Z 轴景深排列（近大远小），围绕头像做轨道旋转，拖动 / 滚轮 / 点击节点置前，悬停查看经历窗口
- 联系方式只在「关于我」页面底部单独列出，不再在头像卡 / 简介中重复

## 首页总看板

- **作品页风格 Hero**：眉标（HOU KANGFENG · FINANCE ARCHIVE 2026）→ 姓名大标题 → 强调句「把账做清楚，把数据变成价值」→ 简介 → 技能标签 → 双按钮（向下看项目 / 项目地图）
  - 右侧装饰卡：项目 KPI 小卡（项目数/合同总额/回款率）+ 个人名片卡（🟢 在职 · 可联系）+ 编号标注 + SCROLL TO EXPLORE 滚动提示
- **顶部滚动进度条**：导航栏顶部随页面滚动填充
- **欢迎 toast**：每次会话首次进入时右下角弹出欢迎卡片
- **项目总看板**：项目数、合同总额、累计完成工作量、累计已收款、整体回款率 —— 全部从项目数据**自动汇总**，增删改项目后实时更新
- **🌐 3D 旋转地球**：真实地球夜景纹理，自动旋转、可拖拽缩放
  - 金色点位 = 工作地点（广州），紫色 = 母校（益阳），青色 = 项目城市（东莞/深圳，点大小随项目数变化），全部**贴球面渲染**（不悬浮）
  - **点击点位 → 地球自动放大到中国区域**（暂停旋转、对准城市），同时弹出项目信息面板：城市级汇总（合同总额/完成/收款/回款率）+ 每个项目的明细卡（含图片位）
  - 放大后可点「🌐 回到全球视角」恢复自动旋转；2D 地图页点击城市同样自动放大聚焦
  - 右侧「地点索引」列表与地图联动，点击同样放大并打开项目面板
  - **滚轮交互**：鼠标在地球/地图区域内滚动 = 缩放图表，页面不滚动；移出图表区域滚动 = 页面平滑滚动（互不冲突）
- **页脚**：技术栈徽章（ECharts / JavaScript / HTML5 / CSS3 / Node.js）+ 社交链接（邮箱 / GitHub）+ 站点运行时间实时计时

## 快速开始（本地版 · 可管理内容）

1. 双击 **`启动网站.bat`**（自动启动服务并打开浏览器 http://127.0.0.1:8765）
2. 点右上角 **「⚙ 管理」** 进入管理模式：
   - 「＋ 新增」下拉选择类型：**项目** / 作品 / 文章 / 经历 / 地点 / 教育 / 特长 / 技能 / 时间轴
   - 「⚙ 管理面板」分类管理：编辑、删除、新增
   - 修改后自动保存到 `data/data.json`（自动备份 `data.json.bak`）

## 项目数据怎么维护

「管理 → ＋ 新增 → 项目」或「管理面板 → 数据 → 项目数据」：

| 字段 | 说明 |
| --- | --- |
| 项目名称 / 城市 | 必填；同一城市自动聚合为一个地球点位 |
| 经度 / 纬度 | 城市坐标，同城项目填相同值（东莞 113.75/23.02，深圳 114.06/22.55） |
| 合同额 / 累计完成 / 累计已收款 | 单位：元，输入原始数字即可，页面自动格式化为亿/万 |
| 项目图片 | 把图片文件放进 `images/` 文件夹，这里填 `images/文件名.jpg`；导出云端时自动复制 |

## 上传云端（静态只读版）

1. 「管理面板」→「🚀 导出静态版」→ 自动生成 `export/` 文件夹
2. 上传 `export/` 全部内容（index.html + assets/ + images/）到 GitHub Pages / Gitee Pages / Netlify
3. 云端版自动隐藏管理功能，内容与本地一致；也可直接发送 `export/index.html` 离线打开

```
侯康峰档案库/
├── 启动网站.bat      ← 双击启动
├── server.js         ← 本地服务（静态 + 数据读写 + 导出）
├── index.html        ← 页面（单页多视图）
├── css/style.css     ← 深空科幻风样式
├── js/app.js         ← 主逻辑（看板/3D 地球/渲染/路由/动画）
├── js/editor.js      ← 管理后台（增删改）
├── js/md.js          ← Markdown 渲染器
├── data/data.json    ← 全部内容数据
├── assets/           ← echarts / echarts-gl / 地球纹理 / 中国地图（离线）
├── images/           ← 项目图片（放这里）
└── export/           ← 导出的静态版（上传云端）
```

## 备份与恢复

- 每次保存自动生成 `data.json.bak`
- 「管理面板 → ⬇ 下载数据备份」随时下载 JSON 备份
- 恢复：把备份内容写入 `data/data.json` 后刷新

## 技术说明

- 纯前端 + 零依赖 Node 服务，无外部 CDN，完全离线可用
- 3D 地球使用 echarts-gl（已本地化）；软件渲染环境（如无 GPU）自动关闭 bloom 辉光保证流畅
- 已知兼容性：echarts-gl 2.0.9 的 `effectScatter3D`/`lines3D` 系列与 echarts 5 核心不兼容，已改用多层 scatter3D 实现脉冲与轮廓效果
